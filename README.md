# Proyecto final MLOps — Netflix Rating Classifier

Este repositorio documenta la construcción reproducible de un sistema
de Machine Learning, desde el entrenamiento y registro del modelo hasta
su despliegue en Kubernetes y el monitoreo de data drift y concept drift.

## Fases

1. Entrenamiento y trazabilidad con MLflow.
2. API de inferencia y contenerización con Docker.
3. Despliegue con réplicas en Kubernetes.
4. Detección de data drift.
5. Detección de concept drift.
6. Interfaz de consumo de la API.
